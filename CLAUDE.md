# Project guidance for Claude Code

Read `AGENTS.md` and `docs/ai-install.md` before helping a user install or configure this project. Those files describe the safe, preview-first workflow and are subordinate to the user's instructions and environment policies.

Do not request or print secrets. Distinguish an isolated CLI profile from an explicit desktop-default change. Preserve unrelated settings and stop for review on ownership, policy, or concurrent-edit conflicts. When working on this repository, use isolated test fixtures; never install into the developer's live environment merely to run tests.
